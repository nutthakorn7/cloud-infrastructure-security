# Quizzes — intentionally empty

Weekly knowledge checks for this course run on **AWS Academy's own Knowledge Checks** inside the
Learner Lab (part of the licensed curriculum), not a separate quiz bank authored here. Per the
licensing terms, no AWS Academy file is copied into this repo (see `../course-plan.md`).

The graded, per-student assessment layer *we* author lives in the labs (`../labs/`) and the research
instruments in `instructor/` (git-ignored). This `quizzes/` directory is deliberately empty (kept
only for layout parity with the two sibling courses). Any original, non-AWS quiz would go here.

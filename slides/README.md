# Slides — intentionally empty

This course wraps AWS Academy's licensed **Cloud Foundations + Cloud Security Foundations**
curriculum, which provides the lecture/slide baseline delivered through AWS's own Learner Lab and
modules. Per the licensing terms, **no AWS Academy file is ever copied into this repo** (see
`../course-plan.md`).

The material *we* author is the assessment layer bolted onto each lesson topic — the labs
(`../labs/`), worksheets, and Audit-the-AI exercises — not a parallel set of lecture slides. So this
`slides/` directory is deliberately empty (kept only for layout parity with the two sibling courses).
If you author any original, non-AWS slides for a lesson, they go here as `slides/lessonNN.md`.
